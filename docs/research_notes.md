# Explored directions

The public default is the final staged combination. Earlier directions motivated its design but are not advertised as supported alternatives or uniformly ineffective algorithms.

| Direction | What was explored | Lesson for the released design |
|---|---|---|
| Repetition-aware control | Exact repeated-step and persistent-prefix gates; local continuations and broader checks | Repetition occurs in both underthinking and overthinking labels. Local shortening did not establish a robust global token benefit. |
| Arithmetic-error intervention | Lightweight contradiction checks and temporary penalty cancellation | Few eligible cases and incomplete correction limited practical value; a local arithmetic fix need not repair the surrounding reasoning. |
| Replacing the dynamic function | Alternative curves, strength changes, compression/recovery combinations | A coefficient change does not guarantee monotonic token reduction. The released reasoning controller remains the frozen adaptation. |
| Error-to-correctness / recovery direction | Class geometry, probes, mixtures and causal interventions | Class separability alone does not establish that adding a mean direction causes correction across questions. |
| State-dependent transforms | Subspace, projection and conditional routing candidates | More elaborate transformations need matched causal evidence, not just attractive geometry. These are not active CLI methods. |
| Forced answer readout | Closing/reading out reasoning with output-level rules | Large accuracy costs led to keeping natural phase transitions in the final route. |
| Answer-stage steering variants | CAA-like means, PCA directions and low-rank operators | Effects were small or heterogeneous. The retained PCA16 configuration is one recorded stage result, not a guarantee of lossless compression. |
| Dynamic lexical penalties | Fixed multiples, linear curves and training-calibrated rational curves | State-dependent logit penalties provided a direct token-cost control path while reusing the existing ReBalance signal. |

These summaries describe the scope and motivation of past research. The repository does not redistribute every abandoned implementation or raw failed output. A negative result for one model, parameter setting or sample set should not be generalized to a universal impossibility result.

Promising future validation includes multi-seed matched-batch comparisons, training-only adjustment of the penalty strength/curve, cross-model SRQ feature collection instead of transferring 1.5B text, and evaluating answer-quality changes separately from reasoning-length changes. Any new fitting should keep the published evaluation identities held out.
